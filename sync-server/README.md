# 區網同步服務

讓 iPhone App 和電腦瀏覽器透過同一個 Wi-Fi 下的 Mac 交換學習進度。資料不經過任何雲端。

## 使用方式

1. 在 Mac 執行：

   ```bash
   corepack pnpm sync-server
   ```

   會先打包網頁，再啟動服務（預設 port 8790）。終端機會顯示電腦網址與手機同步網址。

2. 電腦：用瀏覽器開 `http://localhost:8790`，按單字頁右上角「同步」。
3. 手機：連同一個 Wi-Fi，打開 App，按「同步」。第一次會跳出「允許尋找本地網路裝置」，要按允許。

建議習慣：換裝置練習前先按一次同步，練完再按一次。

## 同步規則

- 資料分 4 種：詞庫進度、設定、單字練習快取、文章練習快取。每種整份覆蓋，不逐字合併。
- 用「內容指紋」判斷哪一邊改過，不比較兩台的時間，所以時鐘不準也沒關係。
- 只有一邊改過 → 自動上傳或下載。
- 兩邊都改過同一種資料 → 跳出詢問，選「保留這台」或「使用另一台」；按 ✕ 表示這次不同步。
- 另一台的 App 版本比較新（資料格式較新）時，會停下來提示先更新。

## 檔案位置

| 檔案 | 位置 |
|---|---|
| 同步檔 | `~/TypeWordsSync/sync.json` |
| 同步檔備份（每次寫入前，留最近 30 份） | `~/TypeWordsSync/backups/` |
| 裝置端下載前備份（只留最近一份） | 裝置 IndexedDB 的 `typewords-lan-sync-backup` |

## 設定

| 環境變數 | 預設 | 說明 |
|---|---|---|
| `TYPEWORDS_SYNC_PORT` | `8790` | 服務 port |
| `TYPEWORDS_SYNC_DIR` | `~/TypeWordsSync` | 同步檔資料夾 |
| `TYPEWORDS_SYNC_URL` | `http://<Mac名稱>.local:8790` | 打包 App 時寫入的預設同步網址（`pnpm generate:app` 自動帶入） |

手機連不到時，App 會讓你手動輸入同步網址（例如 Mac 改名或換 port 後）。
